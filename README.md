# ABL PIXELFORGE — Compresor Profesional de Imágenes para Windows 11

Compresor y optimizador profesional de imágenes para Windows 11 desarrollado por **Aritz Bahamonde Larxé**.

## Características Principales
- **Optimización Multimotor Real:** OxiPNG, libwebp y libavif (Sharp/libvips nativo sin dependencias externas).
- **3 Modos de Compresión:**
  - Modo 1: Sin pérdida real verificada matemáticamente píxel a píxel.
  - Modo 2: Máxima calidad visual (Lossy con perfiles 95%, 90%, 85%, 80% y personalizado).
  - Modo 3: Compresión inteligente automática con análisis de contenido y límite de peso.
- **Verificación Matemática de Integridad:** Inspección y normalización RGBA píxel a píxel independiente.
- **Comparador Visual Interactivo:** Modo cortina / slider, side-by-side, zoom 2x/4x y patrón de transparencia.
- **Procesamiento por Lotes:** Concurrencia controlada para equipos modestos (8 GB RAM).
- **Historial y Métricas:** Registro detallado de operaciones, porcentajes reales de ahorro y tiempos.
